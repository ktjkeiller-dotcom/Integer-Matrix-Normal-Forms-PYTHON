# Integer-Matrix-Normal-Forms-PYTHON
Algorithms to compute Smith and Hermite Normal Forms over several different Euclidean Domains

Code extended from: https://github.com/corbinmcneill/SNF.git
- with added rings: zqsrt (integers of the form a + b*sqrt2), z8 (cyclotomic integers of order 8)
- with added hermite normal forms (row-wise and column-wise (to be done))
- added method to check uniqueness of two hermite normal forms (to be done for column-wise)
